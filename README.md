# 기초 수학에서 LLM까지 — 예제 소스 코드

손으로 계산하고 파이썬으로 이해하는 기초 수학
수학 포기자와 왕초보자를 위한 머신러닝·딥러닝·LLM 수학 입문

## 실행 환경
- Python 3.12 (3.10 이상이면 모두 동작)
- numpy, matplotlib

```
pip install numpy matplotlib
```

## 실행 방법
각 장 폴더에서 실행하는 것을 기준으로 작성되었습니다.

```
cd ch01
python 02_numbers/compare.py
```

Windows 기준 예제이므로 macOS·Linux에서는 `python` 대신 `python3`를
사용하십시오.

## 폴더 구성
- ch01 : 숫자와 계산의 기초
- ch02 : 분수·비율·백분율과 수학적 표현
- ch03 : 문자·방정식·함수·그래프
- ch04 : 통계·확률·데이터 분석 수학
- ch05 : 머신러닝을 이해하는 수학
- ch06 : 딥러닝과 LLM을 이해하는 수학

## 참고
- 그래프를 그리는 예제는 PNG 파일을 현재 폴더에 저장합니다.
- `input()`을 사용하는 예제는 터미널에서 직접 값을 입력해야 합니다.
- 난수를 사용하는 예제는 씨앗값(seed)을 고정해 두어 결과가 항상 같습니다.
